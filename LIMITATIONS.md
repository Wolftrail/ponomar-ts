# Limitations

This is a fresh implementation and currently provides only the Julian Pascha calculation. It does not yet port date arithmetic, Gregorian conversion, movable feasts, service composition, readings, fasting rules, localization, or the original desktop interface.

Behavior is being added incrementally against the upstream Ponomar Java project. Until a feature is implemented and tested, this package should not be treated as a drop-in replacement for Ponomar.
